# 전시 큐레이션

서울에서 열리는 전시 18개를 달력과 지도로 골라 보는 정적 사이트입니다.
빌드 과정 없이 그대로 서빙하면 됩니다.

## 구조

| 경로 | 버전 | 차이 |
|---|---|---|
| `/` | — | A · B · C 로 가는 시작 페이지 |
| `/a` | A | 날짜와 장소 중 **한 가지만** 선택. 지하철 노선 표시 없음 |
| `/b` | B | 날짜와 장소를 **여러 개** 선택. 지하철 노선 표시 |
| `/c` | C | B에 더해 **관람 시간대**와 **지하철 노선별 필터** |

A와 B는 UI가 같습니다. 둘의 차이는 선택 방식과 지하철 노선 표시뿐이라,
비교했을 때 나오는 차이가 디자인이 아니라 동작에서 온 것이 됩니다.

각 페이지는 포스터·지도·글꼴까지 전부 담은 단일 HTML 파일(약 1.5MB)이며,
외부 요청이 없어 오프라인에서도 열립니다.

## 배포

Vercel에서 이 저장소를 Import 하면 됩니다.

- Framework Preset — **Other**
- Build Command — 비움
- Output Directory — 비움 (저장소 루트를 그대로 서빙)

이후 `main`에 push할 때마다 자동으로 다시 배포됩니다.

## 분석

Google Analytics 4를 붙일 수 있게 되어 있습니다. 측정 ID를 넣어 다시 빌드하면
아래 이벤트가 전송되며, 모든 이벤트에 `variant`(`A`/`B`/`C`)가 함께 붙어
버전별로 나눠 볼 수 있습니다.

`session_start` · `calendar_click` · `map_click` · `time_click` ·
`metro_click` · `detail_open`

측정 ID가 없으면 분석 코드 없이 그대로 빌드됩니다.

브라우저 콘솔에서 `storage.report()` 를 치면 그 브라우저에 쌓인 기록만
따로 볼 수도 있습니다. 이 기록은 localStorage에만 남고 어디로도 전송되지 않습니다.

## 데이터

전시 정보는 노션 큐레이션과 서울시 공식 관광정보(visitseoul.net)에서 모았고,
지도는 OpenStreetMap 지오메트리를 단순화해 벡터로 그렸습니다.

운영시간은 18개 중 14개가 요일별로 구조화되어 있습니다. 나머지 4개
(큐비스트, 우리들의 밥상, 맥스 시덴토프, MMCA 다원예술)는 공식 페이지에서
시간을 확인하지 못해 비워 두었고, 시간대로 거르면 목록에서 빠집니다.
